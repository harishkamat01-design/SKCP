# Repository Conventions

## Documentation Philosophy

Learning should never be interrupted for documentation.

Instead:

1. Learn
2. Discuss
3. Discover
4. Capture everything during End Of Day (EOD)

This keeps the learning flow natural while ensuring nothing important is lost.

---

## Repository Rule

- 01–98 → Learning and reference documents
- 99 → Lessons Learned (created only after sufficient experience)

---

## Documentation Order (EOD)

1. README.md
2. CHANGELOG.md
3. Daily Journal
4. Learning Documents
5. Architecture Documents
6. Git Commit

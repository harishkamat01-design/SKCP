## 7. Issue Resolved
Problem

created_at cannot be NULL

---
### Root Cause
Entity was not populating the createdAt field correctly.

Solution:

Implemented

```java
@PrePersist
public void prePersist() {
    this.createdAt = LocalDateTime.now();
}
```
Rebuilt application.

Issue resolved successfully.

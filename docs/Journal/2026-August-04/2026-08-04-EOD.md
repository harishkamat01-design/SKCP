## Supplier PUT

Successfully updated supplier.

Verified:

- Name update
- Phone update
- WhatsApp update
- Address update

Issue found:

createdAt became NULL.

Root Cause:

Entire Supplier object from request replaced the existing entity.

Solution:

The update logic must preserve immutable fields instead of overwriting them.

Fixed by copying:

```java
supplier.setCreatedAt(existingSupplier.getCreatedAt());
```

Result:

createdAt is now preserved correctly.
